# MiniStats

**메뉴바에서 Mac의 CPU·메모리를 모니터링하고, 오래된 DerivedData를 골라 정리합니다.**

Apple Silicon용 네이티브 macOS 앱입니다. AppKit과 SwiftUI로 만들었으며 외부 패키지 없이 빌드합니다.

## 주요 기능

| 기능 | 내용 |
| --- | --- |
| 메뉴바 | 위쪽 CPU, 아래쪽 메모리 사용률. 스토리지 사용률 50% 이상이면 경고 아이콘 표시 |
| 대시보드 | 실시간 수치와 그래프, CPU·메모리 상위 프로세스 3개, 네트워크·스토리지·배터리 상태 |
| 프로세스 상세 | CPU·메모리 카드에서 상위 5개 이름·PID·사용량 확인. 메모리 압력과 스왑 표시 |
| DerivedData 정리 | 8시간 이상 사용하지 않은 캐시 조회, 항목별 선택과 용량 합계, 삭제 전 확인 |
| macOS 연동 | 로그인 시 자동 실행, 스토리지 알림, 활성 상태 보기·Finder 바로가기 |

macOS 26 이상에서는 네이티브 유리 효과를, macOS 13~25에서는 시스템 반투명 소재를 사용합니다. 시스템 외관과 투명도 줄이기·동작 줄이기 설정을 따릅니다.

## 빌드와 실행

- **실행 환경:** Apple Silicon, macOS 13 이상, `/usr/bin/python3`.
- **빌드 환경:** macOS 26 SDK 이상을 포함한 Xcode 또는 Command Line Tools.

```sh
make verify
open build/MiniStats.app
```

결과 앱은 `build/MiniStats.app`, 검증 로그는 `build/logs/`에 생성됩니다. 로컬 빌드는 ad-hoc 서명을 사용합니다.

첫 실행에 알림 권한을 요청하고 로그인 자동 실행을 등록합니다. 자동 실행은 앱 설정에서 해제할 수 있습니다.

## DerivedData 정리

스토리지 카드에서 **8시간 이상 사용하지 않은 후보 중 선택한 항목만** 확인 후 영구 삭제합니다. 자동 삭제는 하지 않습니다.

- 앱 시작 시와 이후 1시간마다 조회하며, 수동 새로고침도 지원합니다.
- 기본 DerivedData 폴더와 Xcode 전역 사용자 지정 위치를 조회합니다. 프로젝트별 상대 경로나 개별 `-derivedDataPath` 위치는 자동으로 포함하지 않습니다.
- 공용 캐시는 기본 보존하며, 옵션으로 포함할 수 있습니다.
- Xcode나 `xcodebuild`가 실행 중이면 정리를 차단합니다. 정리 중에는 새 빌드를 시작하지 마세요.
- 선택한 항목이 사라졌거나 최근 사용되었다면 삭제 전에 중단합니다. 삭제 직전 경로·활동 시각을 재검사하며 심볼릭 링크와 미확인 항목을 보호합니다.

최근 조회와 정리 결과는 `~/Library/Application Support/MiniStats/`에 저장합니다.

## 동작과 범위

- CPU·메모리·네트워크는 **3초마다** 갱신합니다. 그래프는 최근 40회, 약 2분의 측정값이며 앱 종료 후 유지하지 않습니다.
- 프로세스는 대시보드가 열려 있을 때만 조회합니다. 메모리 순위는 첫 조회부터, CPU 순위는 두 번째 조회부터 표시됩니다. 접근 가능한 현재 사용자 소유 프로세스만 포함하며, 헬퍼는 각각 표시합니다.
- 네트워크는 활성 `en*` 물리 인터페이스의 합계입니다. 가상 인터페이스별 통계는 제공하지 않습니다.
- 디스크는 1분마다, 대시보드를 열 때도 확인합니다. 홈 볼륨 사용률이 **50% 이상**이면 알림을 한 번 보내며, 기준 아래로 내려갔다가 다시 넘으면 재알림합니다. 알림 권한과 무관하게 메뉴바 경고는 표시됩니다.

GPU·센서·팬 제어, 코어별 사용률, 디스크 I/O 속도, 장기 기록 저장과 자동 업데이트는 제공하지 않습니다.

## 개발

`make verify`는 릴리스 빌드와 전체 검사, `make debug`는 디버그 빌드와 검사, `make test-python`은 정리 도구 회귀 검사입니다. 삭제 검사는 임시 폴더만 사용합니다.
