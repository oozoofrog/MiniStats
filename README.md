# MiniStats

Apple Silicon용 작은 네이티브 macOS 메뉴바 모니터. 외부 패키지는 사용하지 않습니다. DerivedData 정리는 앱에 포함된 Python 표준 라이브러리 도구로 실행하며, 이 Mac의 `/usr/bin/python3`을 사용합니다.

- 메뉴바: 위쪽 CPU, 아래쪽 RAM 사용률을 이름 없이 백분율 수치만 표시합니다. 38pt 고정 폭에서 숫자를 가운데 정렬하며, 홈 볼륨 사용률이 **50% 이상**이면 주황색 경고 아이콘을 추가합니다.
- 메뉴바를 클릭하면 CPU·메모리 큰 수치, 최근 추이, 상위 프로세스 3개, 네트워크와 스토리지를 한 화면에서 볼 수 있습니다.
- CPU·메모리 카드를 누르면 상위 5개 프로세스의 이름·PID·사용량을 표시합니다. CPU/메모리 탭으로 정렬을 전환합니다. CPU 상세에는 사용자/시스템 비율과 로드 평균, 메모리 상세에는 앱/Wired/압축 구성·스왑·메모리 압력을 표시합니다.
- macOS 26 이상에서는 네이티브 `NSGlassEffectView`를 사용합니다. macOS 13~25는 시스템 반투명 소재를 사용하며, 밝은/어두운 모드와 투명도 줄이기·동작 줄이기 설정을 따릅니다.
- CPU·메모리·네트워크는 3초마다, 디스크는 1분마다 및 대시보드를 열 때 확인합니다. 추이는 최근 40회(약 2분)의 실제 측정값이며 실행 중에만 유지합니다.
- 프로세스 순위는 대시보드가 열려 있는 동안만 백그라운드에서 조회합니다. 메모리 순위는 첫 조회에, CPU 순위는 두 번째 조회부터 표시됩니다. 화면을 닫거나 잠자기에서 깨어나면 CPU 측정 기준을 새로 잡습니다.
- 프로세스 순위는 현재 사용자 소유 프로세스만 포함합니다. root 소유 프로세스(WindowServer, kernel_task, mds 등)는 권한상 읽을 수 없어 CPU 합계와 순위 합이 다를 수 있습니다. 헬퍼 프로세스는 부모 앱으로 묶지 않고 자기 이름으로 표시합니다. CPU %는 코어 1개 = 100%, 메모리는 활성 상태 보기의 ‘메모리’ 열과 같은 기준(phys_footprint)입니다.
- 디스크 사용률 = `(전체 - 여유 공간) / 전체`. 50% 이상이면 macOS 알림을 한 번 보내며, 50% 미만으로 내려간 뒤 다시 50% 이상이 되면 재알림합니다. 알림 전송 여부는 재실행 후에도 유지됩니다.
- 알림 권한은 첫 실행에 요청합니다. 권한이 꺼져 있어도 메뉴바 경고는 유지되며 `설정 → 스토리지 알림 설정…`에서 설정을 열 수 있습니다. 시스템의 집중 모드나 알림 설정에 따라 배너가 표시되지 않을 수 있습니다.
- 메모리 = 비제거성 내부 페이지 + wired + 압축 메모리. 파일 캐시 제외.
- 네트워크 = 활성 `en*` 물리 인터페이스 합계. VPN/브리지의 중복 집계를 피하며, 가상 인터페이스별 통계는 제공하지 않습니다.
- 첫 실행에 로그인 자동 실행을 등록합니다. 설정에서 해제할 수 있습니다.
- 센서/팬 제어, GPU, 코어별 사용률, 디스크 I/O 속도, 기록 저장, 업데이트 서비스는 포함하지 않습니다.

## DerivedData 정리

기존 `~/.local/bin/deriveddata`의 구현을 `deriveddata.py`로 옮겨 앱에 포함했습니다. 별도 DerivedData Menu 앱을 실행할 필요가 없습니다.

- `스토리지 정리`에서 전체 용량, 정리 후보, 프로젝트별 용량을 확인하고 Finder에서 해당 폴더를 열 수 있습니다.
- 첫 실행과 1시간마다 백그라운드로 조회합니다. 새로고침 버튼로 수동 갱신할 수 있습니다.
- **8시간 이상 사용하지 않은 후보 중 체크한 항목만**, 확인 창에서 `정리 실행`을 눌렀을 때 영구 삭제합니다. 알림이 자동 삭제를 실행하지 않습니다.
- Xcode 및 xcodebuild가 실행 중이면 삭제를 차단합니다. 공용 캐시는 기본 보존이며 옵션으로 포함합니다.
- 기본 DerivedData 위치와 Xcode 전역 사용자 지정 위치를 조회합니다. 프로젝트별 상대 경로나 개별 `xcodebuild -derivedDataPath` 위치는 포함하지 않습니다.
- 선택 목록 전체를 다시 조회한 후보와 대조하며, 선택한 항목이 사라졌거나 최근 사용되었다면 삭제 전에 중단합니다. 삭제 직전에도 활동 시각과 경로를 다시 확인하고, 심볼릭 링크 및 미확인 항목을 보호합니다.
- 용량은 할당 블록 기준입니다. APFS 공유 블록 때문에 실제 확보 공간과 다를 수 있습니다.
- 최근 조회 및 정리 결과: `~/Library/Application Support/MiniStats/`.

## 빌드와 검사

Xcode 또는 Command Line Tools가 설치된 Apple Silicon Mac에서:

```sh
make doctor
make verify
```

`build/MiniStats.app`에 최적화 빌드 후 ad-hoc 서명, `--self-test`, `tests/test_deriveddata.py`, 번들·서명·arm64 검사를 실행합니다. 전체 로그는 `build/logs/`에 남습니다. 기존 `./build.sh`도 빌드·서명·Swift/Python 검사를 그대로 실행합니다. CPU·네트워크 계산, 프로세스 순위와 PID 재사용 처리, 스토리지 49.99%/50%/50.01% 경계와 정리 가능 공간 계산, 조회 결과 검증, 임시 폴더에서의 삭제·보존·동시 작업 검사를 포함합니다. 테스트는 실제 DerivedData를 삭제하지 않습니다.

디버거용 앱은 `make debug`로 `build/debug/MiniStats.app`에 생성합니다. 프로젝트 구조, Astra 설정, 변경별 검증과 GUI 확인 절차는 [개발 안내](docs/DEVELOPMENT.md)를 참고하세요.

앱을 종료한 뒤 `open build/MiniStats.app --args --preview-storage-warning`으로 55% 경고와 ‘테스트’ 알림을 확인할 수 있습니다. 디스크를 채우거나 캐시를 삭제하지 않습니다. 종료 후 인수 없이 실행하면 실제 사용률로 돌아가며 테스트 알림을 지웁니다.

실행: `open build/MiniStats.app`. 설치는 원하는 경로(예: `~/Applications/MiniStats.app`)를 선택합니다. 업데이트하려면 메뉴에서 MiniStats를 종료한 후 빌드 결과를 선택한 경로로 복사하고 다시 실행합니다. 빌드 명령은 설치본을 덮어쓰지 않습니다.

로그인 자동 실행은 [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice)를 사용합니다. macOS가 승인을 요구하면 설정의 자동 실행 항목으로 시스템 설정을 열 수 있습니다.

정리 알림은 [Apple User Notifications](https://developer.apple.com/documentation/usernotifications)를 사용합니다.
